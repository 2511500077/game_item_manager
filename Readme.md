# Game Item Manager

## Tentang Project

Game Item Manager adalah aplikasi untuk membantu reseller
item game mengelola inventory, transaksi, dan keuntungan.

## Latar Belakang

Saya memiliki pengalaman sebagai reseller item game.
Seiring bertambahnya item dan transaksi, pengelolaan data
menjadi semakin sulit jika dilakukan secara manual.

Karena itu, saya ingin membuat sistem sendiri untuk membantu
mengelola item, transaksi, dan profit.

## Tujuan

- Mengelola inventory item game
- Mencatat transaksi pembelian
- Mencatat transaksi penjualan
- Menghitung keuntungan
- Menampilkan ringkasan melalui dashboard

## Target Pengguna

Reseller item game.
